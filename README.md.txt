
# Interactive To-Do List Web Application

## Project Description
This is a simple and responsive To-Do List web application developed using HTML, CSS, and JavaScript. It helps users manage their daily tasks easily.

## Features
- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks
- Display total and completed task counts
- Save tasks using browser Local Storage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Add and manage your tasks.

This project helped me understand DOM manipulation, JavaScript events, arrays, functions, Local Storage, responsive CSS, and basic software testing.
